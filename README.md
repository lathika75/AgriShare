# 🚜 Farm Equipment Sharing Platform

A web-based platform that connects farmers with nearby agricultural equipment owners, allowing farmers to search, request, and rent farm machinery at affordable prices.

## 📌 Project Overview

Many small-scale farmers cannot afford expensive agricultural machinery such as tractors, harvesters, rotavators, and seed drills.

At the same time, many equipment owners have machines that remain unused for long periods.

The **Farm Equipment Sharing Platform** provides a digital marketplace where farmers can find nearby equipment owners, send booking requests, and rent agricultural machinery easily.

The platform aims to reduce farming costs, improve equipment utilization, and support rural agriculture.

## 🎯 Objectives

- Connect farmers with nearby equipment owners.
- Provide affordable agricultural machinery rentals.
- Simplify equipment searching and booking.
- Allow owners to list and manage their equipment.
- Enable booking approval and contact sharing.
- Improve agricultural equipment utilization.

## ✨ Main Features

### 👨‍🌾 1. Farmer Module

- Farmer login.
- Search available agricultural equipment.
- View equipment details and rental prices.
- View equipment location.
- Send booking requests.
- Check booking status.
- Contact equipment owners after approval.
- Provide ratings and feedback.

### 🚜 2. Equipment Owner Module

- Owner login.
- Add new agricultural equipment.
- Enter equipment name and rental price.
- Provide equipment location and contact details.
- Manage equipment listings.
- Receive booking requests.
- Accept or reject booking requests.

### 🧑‍💻 3. Admin Module

- Monitor registered platform data.
- View uploaded equipment.
- Monitor booking requests.
- Manage equipment listings.
- Maintain platform information.

## ⚠️ Current Project Limitations

This version is a frontend prototype.

- Data is stored in browser LocalStorage.
- It does not use a centralized backend database.
- Login is a demonstration and is not secure authentication.
- Payment is not connected to a real payment gateway.
- Location and distance information are demonstration data unless connected to a location service.
- Multiple users on different devices cannot share data through LocalStorage.
